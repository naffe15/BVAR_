EMT Function Map

Every function file in bvartools/ and cmintools/, classified by whether something in the toolbox actually reaches it. A function counts as used if one of the 25 example scripts calls it, or if it is called (directly or as a string handle passed to an optimizer) by a function that is itself used. Descriptions are the first line of each function's help. This page is generated by docs/build_function_map.m; run it again after changing the toolbox.
